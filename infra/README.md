# Phase 3 Deferred Infrastructure

Do not stand this stack up for Phase 0-2.

The first certified partner, first routed file, and first commission path run on Netlify + Supabase + SendGrid + DocuSign. The VPS stack is preserved only as a Phase 3 option for owned sourcing/orchestration automation after a real funded deal proves Phase 2.

Current Phase 3 candidates:

- n8n for sourcing/enrichment orchestration.
- Watchtower for low-touch container updates.
- Caddy for TLS routing if/when a VPS is needed.
- DocuSeal only as a future free e-sign fallback if DocuSign cost becomes a problem.
